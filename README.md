# pericyte-counter
Automatic Pericyte Density Calculator

This algorithm calculates pericyte density from multicolor fluorescene images automatically. For more details, please check our article below:

Atak, D., Yıldız, E., Özkan, E., Yousefi, M., Özkan, A., Yılmaz, A. B., ... & Vural, A. (2025). Longitudinal Investigation of Brain and Spinal Cord Pericytes After Inducible PDGFRβ+ Cell Ablation in Adult Mice. Journal of Neurochemistry, 169(3), e70035.
